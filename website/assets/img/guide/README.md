# 연결 안내 페이지 사진 슬롯

여기에 파일을 넣고 생성기를 다시 돌리면, 해당 자리의 도해가 그 사진으로 바뀐다.
파일을 빼면 도해로 되돌아간다. 어느 쪽이든 페이지가 비는 일은 없다.

확장자는 `.webp` `.jpg` `.jpeg` `.png` 중 아무거나 되고, 앞에 오는 순서대로 찾는다.

## 슬롯 이름

| 파일 이름 | 그 자리에 지금 들어 있는 도해 |
|---|---|
| `guide-hotspot` | 1단계 · 휴대폰 핫스팟 설정 화면 (니콘) |
| `nikon-01-type` | 3단계 · 연결 유형 (카메라 제어 / 사진 전송) |
| `guide-05-network` | 2단계 · 카메라의 Wi-Fi 네트워크 목록 (니콘) |
| `nikon-04-method` | 2단계 · 연결 방법 선택 (Wi-Fi 검색 / 간편 연결) |
| `nikon-07-ip` | 2단계 · IP 주소 얻는 방법 (자동 / 직접) |
| `nikon-08-pairing` | 4단계 · 페어링 대기 화면 (SnapBridge 안내) |
| `nikon-09-allow` | 5단계 · 연결 허용 확인 화면 |
| `guide-app` | 4단계 · CamCon 검색 결과 (니콘) |

캐논·소니·후지는 접두어만 다르다: `gc-` `gs-` `gf-`
예) `gc-hotspot` `gc-05-network` `gc-app`

## 주의

- **권리가 있는 파일만 넣는다.** 직접 촬영·캡처한 것이거나 사용 허락을 받은 것이어야 한다.
  이 저장소는 공개 미러(CamCon_Pub)로 그대로 밀려 나가므로, 한 번 들어가면 히스토리에 남는다.
- 도해는 글자가 번역 사전에 있어 8개 언어로 읽히지만, **사진은 찍힌 언어 그대로 모든 언어판에 나온다.**
  한국어 메뉴 사진을 넣으면 독일어 페이지에서도 한국어 메뉴가 보인다.
- 가로 330px 안에서 표시되므로 그보다 크게 넣을 이유는 없다. webp 권장.
